# 词间阅读器

本地运行的 TXT/EPUB 中英混读阅读器。书籍由浏览器在本机解析；只有点击“AI 生成本章”后，当前批次的段落才会发送到阿里云百炼。

## 当前实现

- 默认使用 `qwen-flash`，网页“API 设置”中可手动输入模型名称，或从已保存模型列表选择，点击“保存并切换”立即生效。所选模型需在当前百炼接口可用，并支持 system 消息和 JSON 输出。
- 默认以重点单词为主，固定术语、搭配和必要语法单位可保留为短语。
- 密度为低 10%、中 20%、高 40%；四级/六级与密度都会写入每次新请求，已有章节内容保持可见。
- 英文替换项可点击切换为对应的原文，再次点击恢复英文。
- 人名、地名、机构名、作品名等专名不参与替换；Prompt 与本地验证器会进行双重拦截。
- 每段都有明确的替换数量/字符目标；明显不足时会自动补选一次，完成状态会显示实际替换数和覆盖率。
- 本地验证器会检查原文精确匹配、重叠、密度和置信度；不安全的建议直接保留中文。
- 支持 UTF-8/GB18030 TXT 和无 DRM 的 EPUB。
- EPUB 的目录、卷名和正文内部链接可以跳到对应章节或锚点。
- 左侧目录与右侧正文独立滚动。
- 浏览器只保存最近导入的一本原书副本；AI 结果在 IndexedDB 中按书籍、章节保留一份共享内容，刷新或重新打开后不重复付费。
- API Key 按模型分别保存在本机 `.model-profiles.local.json`。新模型首次填写 Key；切回已保存模型时 Key 留空，自动使用对应配置。最后使用的模型也会保留，重启无需重填。网页不缓存或回显 Key。
- 原来 `.env.local` 的模型与 Key 会在首次升级启动时自动迁入新配置，原文件保持不变。之后以新配置为准。
- 多个模型共同创作同一份章节内容，切换模型、思考档位、等级、密度或提示词版本不会隐藏已有结果，也不会调用 AI；这些设置只影响以后提交的请求。
- 同一段的多个成功结果按生成时间决定，最后一次结果整段覆盖之前的替换列表；最新结果为空也会覆盖。未重新生成的段落保留旧内容。
- 打开书籍时会将原来按模型/思考模式分开的历史缓存按段合并，在同一 IndexedDB 事务中保存共享记录并移除重复旧记录；事务失败会回滚。旧数据以原记录保存时间排序，新数据以逐段生成时间排序，刷新和保存进度不会改变段落的新旧顺序。
- “思考强度”下拉框提供关闭（默认）、低、中、高、最大，随各模型的 Key 一起保存在本机。Qwen 混合模型使用 1024/4096/8192/16384 Token 的思考预算，并额外预留最终 JSON 的输出预算。DeepSeek-V4 使用原生 reasoning_effort：基础版仅高/最大；flash-0731、pro-0813 支持低/高/最大。不具备独立效果的档位禁用，后端也拒绝，避免低/中被平台悄悄映射为高。其他模型透传 effort 档位，实际兼容性以接口为准。非关闭档位采用流式读取并校验最终 JSON。旧“开启”配置迁为高，旧“模型默认”迁为关闭。
- “并行批数”可选 1–6，默认 3；每批最多 2 段。同一章节同一配置的多标签页生成使用浏览器锁防止重复提交。
- 每批结果返回后立即写入 IndexedDB，逐段记录完成状态（包括合法的零替换结果）。点击“AI 生成 / 继续本章”会读取进度，只提交缺失段落；并行乱序返回不会覆盖其他批次的结果。已完成章节再次点击不会调用 API。
- 429 速率限制最多自动退避重试两次（遵循 Retry-After；过长则暂停）；额度/余额不足、鉴权失败和其他错误停止新批次，已发出的成功结果仍保存。网络超时不自动重试，避免不明确的重复计费。
- “暂停并保存”停止派发新批次，并等待进行中的请求收尾。刷新/重启后可续译，但强行关闭时尚未返回或尚未落盘的批次可能需要重做。旧版本未保存的半章无法凭空恢复。
- 续译可以更换模型、思考档位、等级、密度、Key 或并行数，已完成段落仍保留，只生成缺失段落。Key 和调用设置仍按模型分别保存，与章节内容分开管理。

系统提示词位于 `prompts/system-prompts.mjs`。

接口依据：[思考模式](https://platform.qianwenai.com/docs/developer-guides/text-generation/thinking)、[结构化输出](https://platform.qianwenai.com/docs/developer-guides/text-generation/structured-output)、[限流](https://platform.qianwenai.com/docs/developer-guides/administration/rate-limits)。思考模式通常会增加延迟和输出 Token，实际并发加速受模型延迟与账号 RPM/TPM 限制影响。

## 启动

首次安装需要 Node.js 20 或更新版本，然后运行：

```powershell
npm install
npm run build
pwsh -File .\install-shortcut.ps1
```

之后双击桌面的“词间阅读器”即可，不需要打开命令行。每次双击都会先停止本项目旧服务、再启动当前代码，并使用带刷新标记的新页面打开。也可以运行 `npm run dev`，再访问 `http://127.0.0.1:4317`。

## GitHub Pages 阅读版

本地完整版左侧的“更新 GitHub Pages 阅读版”会把最近一本原书和已经保存的双语结果写入 `pages-reader/public/library`，并构建 `pages-reader/dist` 供本机预览。这个静态版保留目录、EPUB 内部跳转、独立滚动和点击中英文切换，不包含 AI 生成、API 设置、Key 或模型信息。

以后生成更多内容后，再点一次更新按钮，然后提交并推送 `pages-reader/public/library`。仓库内的 `.github/workflows/pages.yml` 会用 GitHub Actions 自动构建并部署。首次发布需在仓库 Settings → Pages 中把 Source 设为 GitHub Actions。详细步骤与内容权利提醒见 `pages-reader/README.md`。

## 本地存储说明

- 原始 EPUB/TXT：只保留最近一本，导入下一本会覆盖上一份浏览器副本；不会复制出无限多份。
- AI 结果：按章节缓存，清除浏览器站点数据前一直可复用。
- 左侧会显示浏览器存储用量，并提供“清除缓存”。清除操作不会删除你原本的 EPUB/TXT 文件。
- 书籍原文不写入项目目录或数据库文件；API Key 单独保存在项目根目录的 `.model-profiles.local.json`（本机明文配置，勿分享）。旧 `.env.local` 作为迁移来源保留，分享项目时也应排除它。
